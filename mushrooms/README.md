About the Dataset
This dataset contains records of hypothetical samples from 23 species of gilled mushrooms in the Agaricus and Lepiota families. Each sample is classified as either edible, poisonous, or of unknown edibility. For practical purposes, the "unknown" class has been merged with the "poisonous" class.

The dataset is commonly used for classification tasks and includes both morphological and environmental features of mushrooms.
